# AL FAHAD Apex Marketing - Lucky Draw Landing Page

This project is a promotional web landing page for `AL FAHAD Apex Marketing` that showcases an online lucky draw ticket purchase experience. The page highlights prizes, draw details, and a ticket order form for potential customers.

## Overview

- `index.html` contains the main landing page content for the lucky draw.
- `style.css` provides the visual design, layout, and responsive styling.
- `app.js` handles mobile menu toggling, video modal interactions, animations, and ticket quantity controls.
- `images/` and `video/` include assets used to showcase prizes and brand visuals.

## Features

- Hero section with draw messaging, ticket pricing, and promotional video.
- Prize highlights including cars, motorcycles, iPhones, and cash prizes.
- Video gallery and prize presentation cards.
- Explanation of how the draw works and the online ticket purchase flow.
- SEO and social sharing meta tags added for better discoverability.

## Files

- `index.html` - main page and content.
- `style.css` - styling and layout.
- `app.js` - JavaScript interactions.
- `images/` - logos and promotional images.
- `video/` - prize and draw videos.

## Usage

1. Open `index.html` in a browser.
2. Click the `Buy a ticket` button or complete the form with your payment screenshot.
3. `app.js` controls mobile navigation, animations, and video playback.

## Purpose

The goal of this project is to provide an attractive, mobile-friendly, and persuasive landing page for a lucky draw campaign so visitors can easily learn about the prizes and buy tickets online.
